# Design.RIP - Master UI Design Elements

**Source:** *[DESIGN.RIP]* image-based EPUB, OCR reviewed.

## Use this for

- Typography and spacing discipline
- Forms, buttons, tables, and navigation
- Fine-grained interface polish

## High-signal insights

1. Typography, spacing, weight, and contrast create most of the perceived quality.
2. Dark is not black, and accessible does not have to look ugly.
3. Labels, placeholders, errors, and keyboard choice in forms are functional decisions.
4. Buttons need explicit padding, hierarchy, and destructive-state rules.
5. Tables need readable spacing, alignment, sticky headers, and efficient filtering.
