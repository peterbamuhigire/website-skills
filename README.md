# Website Skills Engine

The Website Skills Engine is a portable library for taking website work from discovery and strategy through content, design and build, quality review, launch, measurement, and maintenance. Its 62 active skills cover agency operations, brand, content and copy, commerce, SEO, user experience, and delivery; workflows connect business goals and user journeys to accessible, performant pages, conversion paths, release evidence, and post-launch improvement. Outputs include project plans, page and content specifications, copy, ecommerce and measurement plans, audits, deployment guidance, and maintenance procedures.

It is for website agencies, freelance developers, in-house marketing and product teams, and the business owners who commission sites. The engine sets a premium delivery standard while keeping scope evidence-based: accessibility, performance, security, and launch gates support review, but a skill or checklist alone is not a certification or proof of a live site's results.

## Installation

For Claude Code, install the native plugin:

```text
/plugin marketplace add https://github.com/peterbamuhigire/website-skills
/plugin install website@chwezi-website
```

Or clone the repository and run its installer (Node.js 18 or later):

```sh
git clone https://github.com/peterbamuhigire/website-skills
cd website-skills
./install.sh --scope project       # macOS, Linux, or Git Bash
.\install.ps1 --scope project      # Windows PowerShell
```
