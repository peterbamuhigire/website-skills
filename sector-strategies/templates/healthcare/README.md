# Healthcare Sector Templates

Design strategy for hospitals, clinics, medical practices, and health service websites.

## Files

| File | Purpose |
|------|---------|
| **sector-brief-template.md** | Customisation questionnaire (REQUIRED) |
| **design-tokens.md** | Reference palette, typography, spacing (DO NOT USE AS-IS) |
| **component-patterns.md** | HTML/Tailwind component examples |
| **component-patterns-full.md** | Extended component library |
| **IMPLEMENTATION-GUIDE.md** | Step-by-step build guide |
| **healthcare-branding.md** | Color psychology, accessibility-first design, typography by facility type |
| **patient-trust-design.md** | Patient funnel, trust architecture, doctor profiles, appointment booking |
| **healthcare-type-patterns.md** | 7 types (hospital, specialist, wellness, paediatric, mental health, dental, diagnostic) |

## Usage

1. Read **healthcare-branding.md** to understand healthcare design psychology and accessibility requirements
2. Read **patient-trust-design.md** for patient trust and appointment conversion patterns
3. Read **healthcare-type-patterns.md** to find your facility type
4. Copy **sector-brief-template.md** to `docs/sector-brief.md` and customise
5. Run the design-system skill

Healthcare sites must be WCAG AAA for body text with 48px minimum touch targets. Accessibility is mandatory, not optional.
