## Cross-cutting findings within the engine

- Strong written quality controls are not yet backed by fixture projects and repeatable, green gate evidence.
- Historic/migrated routing has drifted: documentation and active references still call local skills that were moved to the external design-system engine.
- The CI template conflicts with the stated portable-resolution contract and references a missing deploy runner.
- Core skills are well referenced, but no-reference skills and the lack of completed examples create uneven delivery quality.
- Standards are named but need a versioned owner-and-review register.

## Upgrade order by return on effort

1. Fix CI/installer paths and add registry validation.
2. Repair all active relocated-skill handoffs and generated documentation counts.
3. Create the baseline benchmark fixture and gate snapshots.
4. Add multilingual and commerce fixtures plus typed project artifacts.
5. Establish independent calibration, production-equivalent benchmark evidence, and quarterly standards governance.
