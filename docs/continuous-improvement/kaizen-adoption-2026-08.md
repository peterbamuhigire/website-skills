# Website Skills — Kaizen Adoption Plan

Baseline: 65/100 capped in the July 2026 engine audit. Target: 95/100; future audits remain capped at 65/100.

## Product scope

Marketing sites, landing pages, ecommerce, portals, dashboards, content hubs, AI-enabled experiences, launch systems, and maintenance/retainer operations.

## P0 changes

- Add `quality-gates/kaizen-engine-and-product-improvement` to the website-builder route and release checklist.
- Create a baseline fixture with strategy brief, typed project artefacts, rendered screenshots, accessibility/security/performance/SEO evidence, and post-launch learning.
- Repair relocated design-system handoffs and require versioned owner/review dates for platform and standards references.
- Strengthen AI UX with problem-first discovery, system-level stakeholder mapping, meaningful friction, trust calibration, control, and drift-aware maintenance.

## P1 changes

- Add Digital Storytelling/Dynamic Characters references for visual narrative, character/brand expression, interactive sequencing, and content-system handoff; route typography/UI to design-system-skills.
- Add XP/Lean references for experiment design, hypothesis logs, value metrics, feedback loops, and maintenance waste reduction.
- Add Facility Move-style cutover, rollback, stabilisation, and closeout to launch operations.

## Acceptance evidence

Run the website validator and quality gates, render the fixture, inspect mobile/accessibility/security/performance/SEO evidence, and record an independent review plus a re-audit.
