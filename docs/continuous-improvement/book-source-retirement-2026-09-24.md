# Book-extractions retirement and where each method now lives — 2026-09-24

## Decision

Owner rule (2026-09-23): book extractions must never be stored in this repository. The
`book-extractions/` folder (50 files) was removed with `git rm -r book-extractions` on
2026-09-24 after every capability it taught was mapped to a task-oriented skill reference.
History was not rewritten.

## Method

1. Every reference to `book-extractions/` across skills, references, routers, docs, scripts and
   universal guidelines was listed (67 references in 41 files).
2. Each of the 50 files was read in full and inventoried item by item (framework, procedure,
   checklist, template, formula, decision rule, phrase pattern, worked-example type).
3. Each item was mapped to an existing skill or reference that genuinely teaches it (EXISTING),
   written into a new task-oriented reference in original words with a brief citation
   (NEW-REF), or dropped with a stated reason (DROPPED: bibliographic detail, verbatim text,
   dated statistics, dead tools or volatile claims only).
4. Every live link was repointed to the successor reference; historical Kaizen records were
   annotated rather than rewritten.
5. `scripts/source_ingestion_guardrail.py` now rejects any file in a `book-extractions/`-style
   folder or with a book-extraction or book-summary file name, whatever its size.

Pure visual-design items that the design engine already teaches were mapped to
`design-system-skills` paths (shown with that prefix). The row-level inventories are held in
the Kaizen ledger for this wave; this table is the durable summary.
