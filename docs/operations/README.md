# Agency Operations

This directory contains the internal operating system introduced by Phase 2 of the
website agency engine roadmap. It standardises how premium website projects are
qualified, discovered, proposed, kicked off, approved, and handed into production.

## Phase 2 Outputs

- `lead-qualification-scorecard.md` - lead fit filter and routing logic
- `intake-questionnaire-template.md` - structured intake and discovery questions
- `discovery-to-build-artifact-map.md` - handoff map into repository skills
- `project-artifact-standard.md` - canonical project folder and artifact set
- `project-stage-gates.md` - explicit approval gates with owners and rollback rules
- `premium-proposal-template.md` - proposal structure for premium website projects
- `kickoff-template.md` - sold-scope to operating-facts conversion

## Operating Rule

No website build starts until:

1. The lead passes the qualification bar or is intentionally routed to a lower-tier path.
2. Discovery inputs are complete enough to produce the required artifacts.
3. The relevant stage gate is approved and recorded in writing.

## Source Logic Used

These assets were shaped by the Phase 2 reading list:

- *Managing the Professional Service Firm* - client listening, service quality, and operating discipline
- *Book Yourself Solid* - selective client fit and trust-first selling
- *SPIN Selling* - diagnostic discovery and question sequencing
- *The Checklist Manifesto* - short, critical stage-gate checklists and pause points

## Use Order

1. Score the lead with `lead-qualification-scorecard.md`
2. Run intake with `intake-questionnaire-template.md`
3. Produce the required project artifacts from `project-artifact-standard.md`
4. Build and approve the proposal using `premium-proposal-template.md`
5. Translate the sold scope into delivery facts with `kickoff-template.md`
6. Govern the project through `project-stage-gates.md`
7. Hand artifacts into downstream build skills using `discovery-to-build-artifact-map.md`
