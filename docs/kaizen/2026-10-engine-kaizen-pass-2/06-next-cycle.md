**Measure:** the count of `not_assessed` entries in `release-evidence.json` falls from 8 to 3 or fewer, each new entry carries the exact command and exit code, and the Lighthouse result is recorded next to the 2,000 ms assertion.
**Stop condition:** the toolchain cannot be locked at exact versions, or the container needs host changes. Record the exact error and leave the gates `NOT_ASSESSED`. Do not relax any budget to make a gate pass.
**Rollback:** delete the container and the scratch project; no engine file changes until the results are reviewed.
