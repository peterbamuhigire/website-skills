# Phase 5 - Conversion, Content, and SEO Engine

## Objective

Turn every website from a visually strong build into a discoverable, persuasive business asset.
This phase productizes copy, conversion structure, content systems, SEO foundations, and authority
signals so premium sites perform after launch.

## Why This Phase Matters

Clients rarely pay $10k+ because they love source code quality. They pay because they want:

- better leads
- stronger trust
- clearer offers
- more search visibility
- a sales process the website supports instead of sabotages

This phase is where that promise becomes operational.

## Core Outcomes

- standardize high-quality website messaging and conversion structure
- build a default SEO and GEO baseline for all premium projects
- create a content architecture system that supports authority and lead generation
- package conversion and SEO work as part of the premium offer, not as an optional afterthought

## Workstreams

### 1. Messaging system

Create a website messaging framework covering:

- headline logic
- subheadline logic
- proof placement
- objection handling
- CTA ladder
- service page structure
- about page trust logic
- FAQ and resistance reduction

This should leverage:

- `content-writing`
- `sales-copywriting`
- `brand-alignment`
- `language-standards`

### 2. Page-level conversion patterns

Each template should define:

- primary CTA
- secondary CTA
- proof blocks
- trust placement
- friction points
- conversion event tracking plan

### 3. SEO and GEO baseline

Create the default premium SEO package:

- keyword and intent map
- page metadata model
- internal linking plan
- schema rules
- local SEO requirements where relevant
- AI visibility and answer-engine readability rules

This should use and refine:

- `seo`
- `seo-audit`
- `blog-writer`
- `blog-idea-generator`

### 4. Authority content system

Premium websites need content depth.

Create a standard for:

- cornerstone service pages
- trust-rich about pages
- case studies
- FAQs
- blog support strategy
- downloadable lead magnets where relevant

### 5. Performance and analytics alignment

Define the minimum instrumentation:

- form submissions
- CTA clicks
- call intents
- WhatsApp or email intents
- scroll depth on key sales pages
- source and campaign tagging where available

## Repository Outputs Required

- messaging framework template
- page conversion checklist
- premium SEO package definition
- authority content matrix
- analytics event map for brochure and lead-gen websites

## Success Criteria

- every page has a persuasion purpose, not just content
- SEO starts in planning, not after development
- the website can prove business value after launch
- the agency can sell strategy plus performance logic, not just design
- content production becomes guided and repeatable

## Risks to Avoid

- treating copy as decoration
- using SEO as metadata only
- relying on blogs without strengthening money pages
- burying trust proof below the fold everywhere
- collecting no analytics and then claiming strategic value

## Reading Material To Buy And Provide At This Stage

- *Everybody Writes* by Ann Handley: disciplined web writing and editorial quality
- *Made to Convert* by Tom Albrighton: conversion copywriting for websites
- *The Copywriter's Handbook* by Robert Bly: direct-response fundamentals that still apply
- *Product-Led SEO* by Eli Schwartz: search strategy tied to business outcomes
