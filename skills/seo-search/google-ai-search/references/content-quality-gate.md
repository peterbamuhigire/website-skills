# Content Quality Gate

Use this gate before page-builder or blog production when a page is expected to
earn visibility in Google's AI Search experiences.

## Pass Conditions

The page must satisfy all of these:

- It answers a real user question or task, not an invented keyword variant.
- It has a distinct point of view, first-hand experience, original proof, or
  practical judgment.
- It is organized for human reading with clear sections and no artificial
  "AI chunking".
- It includes concrete facts where useful: audience, location, price posture,
  process, evidence, limitations, requirements, or next step.
- It uses high-quality images or video when media improves understanding.
- It avoids padded FAQs and generic listicle sections.
- It links to deeper supporting pages where a reader naturally needs more.
- It can be maintained when facts change.

## Fail Conditions

Reject or rework the page when it is:

- a lightly rewritten summary of existing search results
- a near-duplicate built for a fan-out query variation
- mostly AI-generated text with no original value
- structured around search-engine tricks instead of user satisfaction
- unsupported by real proof in trust-sensitive sectors
- dependent on hidden schema or crawler files to carry meaning

## Review Questions

Ask:

- What does this page say that a generic AI model or competitor summary would
  not say?
- What first-hand experience, data, or operational proof supports it?
- Would the target visitor feel satisfied after reading it?
- Is there a better single comprehensive page instead of multiple thin pages?
- Does the page make the next step obvious without forcing a conversion too
  early?

## Handoff Notes

For `premium-commercial-writing`, provide:

- primary user question
- audience and buying stage
- original proof available
- required facts and sources
- claims that need qualification
- internal links and conversion path

For `seo`, provide:

- canonical slug
- title and description direction
- schema candidates that match visible content
- image/video SEO notes
- Search Console measurement target
