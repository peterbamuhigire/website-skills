# Voice Profile Schema

**Read this when**: building or reusing a `VOICE PROFILE` under
`skills/content-copy/brand-voice/SKILL.md`.

Adapted from ECC's `skills/brand-voice/references/voice-profile-schema.md`
structure, generalised for a multi-client agency engine (no single default
persona) and joined to this engine's mechanical banned-phrase gate.

Use this exact structure when building a reusable voice profile:

```text
VOICE PROFILE
=============
Client:
Confidence: (high | low-confidence — state why if low)
Sample Count:
Sample Dates: (earliest–latest)

Source Set
- source 1 (channel, date)
- source 2 (channel, date)
- source 3 (channel, date)

Rhythm
- sentence length, pacing, and fragmentation, with a source reference

Compression
- how dense or explanatory the writing is, with a source reference

Capitalisation & Punctuation
- conventional, mixed, or situational, with a source reference

Question Use
- rare, frequent, rhetorical, direct, or mostly absent, with a source reference

Claim Style
- how claims are framed, supported, and sharpened, with a source reference

Preferred Moves
- concrete moves the author does use, each with a source reference

Banned Moves
- specific patterns the author's real samples never use
- cross-reference: which entries from banned-phrases.md also apply here

Channel Notes
- Web:
- Email:
- Social:
- (add or omit channels to match the actual source set)
```

Guidelines:

- Keep the profile concrete and source-backed — every line should be
  traceable to a specific sample, not a general impression.
- Use short bullets, not essay paragraphs.
- Every `Banned Moves` entry should be observable as absent across the
  source set, or explicitly requested by the client.
- If the source set conflicts (e.g. two writers with different habits),
  say so instead of averaging it into a voice nobody actually uses.
- A `low-confidence` profile is still usable — state the gap so downstream
  skills can qualify their output rather than overstate certainty.
