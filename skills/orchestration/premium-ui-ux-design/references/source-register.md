# Source Register

## Active provenance

No active source path or third-party library metadata is asserted here. The
parent skill contains independently structured operational guidance and must
remain usable after any temporary source material is removed.

## Quarantined provenance

A previous version recorded local EPUB paths, including entries containing
third-party library-site metadata. Those identifiers are intentionally removed
from the active register and must not be used as authority, attribution, or
rights evidence.

## Reuse rule

Re-add a source only after its author, title, issuing publisher or organisation,
stable primary record, access date, applicability, and rights to distil the
material have been verified. If that evidence is unavailable, record the gap as
`NOT ASSESSED` and keep the operational rule self-contained.
