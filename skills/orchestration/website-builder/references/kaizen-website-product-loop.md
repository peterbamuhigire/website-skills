# Kaizen Website Product Loop

Use after discovery, each major build iteration, launch, and the maintenance review.

Baseline page goals, audience tasks, content proof, accessibility, responsive behaviour, visual consistency, performance, security, SEO/GEO, conversion ethics, analytics, and handoff. Choose one high-leverage defect. State a hypothesis, expected user/business signal, guardrail, timebox, owner, and rollback. Test with rendered screenshots plus user or analytics evidence. Standardise in the design/content/build system only after the relevant quality gates pass.

For AI-enabled sites, include model/system/data/inference transparency, correction and escalation paths, privacy controls, drift monitoring, and a non-AI fallback. For visual work, consult design-system-skills.
