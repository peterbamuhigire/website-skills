# Phase 7 - Proof, Authority, and Lead Generation

## Objective

Build the agency growth layer around the delivery engine so the business can attract premium
projects consistently instead of depending on referrals and chance.

## Why This Phase Matters

A world-class agency engine is incomplete if it can deliver brilliantly but cannot reliably
generate demand. The repository already includes assets for content, SEO, brand alignment, and
sector positioning. This phase turns those into a client acquisition system.

## Core Outcomes

- create proof assets that justify premium pricing
- build an authority-driven marketing system for the agency itself
- standardize case studies, audits, and thought-leadership content
- create lead-generation pathways aligned with the premium offer

## Workstreams

### 1. Build proof assets

Create standard formats for:

- case studies
- before/after breakdowns
- design rationale snapshots
- launch outcome summaries
- client testimonial capture
- authority pages for the agency website

### 2. Develop an agency content system

Use the same repository as dog food.

The agency should publish:

- high-intent service pages
- sector-specific landing pages
- expert blog articles
- audit-based lead magnets
- website teardown content

### 3. Create premium lead magnets

Examples:

- website authority audit
- trust and conversion review
- SEO foundation review
- messaging clarity review

These should feed qualified conversations, not free consulting traps.

### 4. Build proposal proof libraries

Create a reusable bank of:

- case study excerpts
- trust metrics
- testimonial snippets
- process diagrams
- launch checklists
- proof of strategic rigor

### 5. Install a lead-generation rhythm

Define a weekly and monthly cadence for:

- publishing
- outreach
- follow-up
- referral asks
- case study collection
- pipeline review

## Repository Outputs Required

- case study template
- agency website content plan
- premium audit offer template
- proof library structure
- editorial calendar for authority content

## Success Criteria

- the agency can show work in a persuasive, repeatable format
- inbound leads encounter strategic proof before sales calls
- content compounds authority in chosen sectors
- audits and insights create conversations with qualified leads
- the agency markets itself using the same standards it sells

## Risks to Avoid

- publishing generic content that does not attract buyers
- treating testimonials as optional
- relying on portfolio screenshots without business context
- giving away deep consulting in lead magnets
- creating inconsistent thought leadership with no niche focus

## Reading Material To Buy And Provide At This Stage

- *They Ask, You Answer* by Marcus Sheridan: authority content that drives sales
- *Content Inc.* by Joe Pulizzi: content as a business-building asset
- *Expert Secrets* by Russell Brunson: positioning expertise and structuring authority offers
- *Show Your Work!* by Austin Kleon: practical habit of making process visible
